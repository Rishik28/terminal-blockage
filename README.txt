BLOCKBOUND v0.3 — Enemy Gauntlet

PLAYABLE BUILD
Open dist/index.html. It is a single self-contained HTML file with all code and artwork embedded.

SOURCE TREE
src/index.html
src/css/style.css
src/js/game.js
src/assets/

REBUILD
Run: python tools/build.py

ENEMIES
Goblin Raider — telegraphed direct HP strike.
Grave Slime — raises the stack with a garbage row.
Chaos Jester — redistributes every locked block on the board.

CONTROLS
Arrow keys: move / soft drop
Space: hard drop
Up or X: rotate clockwise
Z: rotate counterclockwise
C: hold
P: pause
